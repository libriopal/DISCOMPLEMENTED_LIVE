# Acceptable Use Policy

**Last updated:** August 21, 2026

## Prohibited Uses

You may NOT use Discomplement to generate, facilitate, or distribute any of the following. Violations result in immediate action as described in the Enforcement section.

### 1. Fraud and Scams

- Phishing sites, fake login pages, credential harvesting tools
- Ponzi schemes, pyramid schemes, guaranteed-return investment scams
- Money-stealing applications, wallet drainers, crypto theft tools
- Fake exchanges, wash trading platforms, market manipulation tools

### 2. Malware and Cyberattacks

- Viruses, trojans, backdoors, rootkits
- Ransomware, file encryption with ransom demands
- Spyware, keyloggers, surveillance tools
- Botnets, DDoS tools, command-and-control servers
- Cryptominers, cryptojacking scripts

### 3. Illegal Drugs

- Drug marketplaces, narcotics distribution platforms
- Drug manufacturing instructions or recipes

### 4. Weapons and Violence

- Weapon blueprints, firearm manufacturing instructions
- Bomb-making instructions, explosive device plans
- 3D-printed weapon files

### 5. Child Safety (Zero Tolerance)

- Any content involving minors in sexual contexts
- CSAM (Child Sexual Abuse Material)
- **Immediate permanent ban + report to NCMEC** (1-800-843-5678 or report.cybertip.org)

### 6. Human Trafficking

- Platforms facilitating human trafficking
- People smuggling operations

### 7. Terrorism

- Terrorist recruitment platforms
- Bomb-making or attack planning tools
- Extremist content distribution systems

### 8. Counterfeit Goods

- Counterfeit product marketplaces
- Fake brand stores, replica selling platforms

### 9. Hate Speech and Harassment

- Doxxing tools, harassment campaign platforms
- Swatting tools, raid coordination
- Hate speech forums, supremacist platforms

### 10. Election Interference

- Disinformation campaign generators
- Fake news creation tools
- Election manipulation platforms

### 11. Copyright Piracy

- Content piracy tools
- Software cracking tools
- DRM circumvention utilities

### 12. Privacy Violations

- Tools designed to expose private information
- Identity theft facilitators
- Stalking and tracking tools

## Enforcement

| Violation Level                                 | Action                                           |
| ----------------------------------------------- | ------------------------------------------------ |
| First violation (non-severe)                    | Warning + content removed                        |
| Second violation                                | 7-day account suspension                         |
| Third violation                                 | Permanent ban + IP block + credit forfeiture     |
| Severe violation (CSAM, terrorism, trafficking) | Immediate permanent ban + law enforcement report |

## How We Detect Violations

Discomplement uses multi-layer detection:

1. **Pattern matching** — regex patterns for known malicious request types
2. **Semantic analysis** — embedding similarity to known malicious patterns
3. **AI classification** — language model classification of intent
4. **Context analysis** — multi-turn pattern detection for incremental malicious builds

Detection runs BEFORE any code is generated. Malicious prompts are denied immediately and flagged. False positives are tested against legitimate use cases to minimize wrongful blocking.
