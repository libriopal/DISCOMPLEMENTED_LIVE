Project Lifecycle
Goal: create, configure, collaborate on, and archive a project without leaving the Workspace zone.

Decision: continue, duplicate, or archive.

Failure & Recovery

Cross-Cutting — Accessibility & Recovery
Resilient by Default
Keyboard-first navigation
Every flow completable without a mouse. Logical tab order, visible focus rings (Ring Blue #4c6ee6), skip links on each screen, and a global ⌘K command palette as the universal entry point.
Screen-reader & motion
ARIA live regions announce stage transitions and approval outcomes. Lattice offers a semantic list fallback. prefers-reduced-motion disables node physics and swaps to instant state changes.
Universal recovery
Every destructive action is undoable via a 10s toast, then restorable from History. Autosave on every stage. Failed generations retain the last good artifact so the user never loses progress.
