Replay Semantics
Play animates node births, edge formations, and confidence shifts chronologically. Scrub to any version to freeze state. Diff mode highlights added (green pulse), removed (red fade), changed (amber ring) between two versions.

Collaboration-ready
Version log is append-only and attributed (who/agent, when, what). Live cursors of collaborators reserved in the schema. Every replay frame is shareable as a deep link.

07 — Performance Strategy
Scaling to 100k+ Nodes
Viewport Virtualization
Only render nodes/edges within the camera frustum + margin. Spatial quadtree index for O(log n) hit-testing and culling.
Level of Detail
Zoomed out → clusters render as single aggregate blobs. Zoom in → clusters expand to individual nodes. Labels appear only above 60% zoom.
Lazy Loading
Graph streams by region — fetch node payloads on demand as the camera moves. Inspector detail lazy-loaded on select. Skeleton nodes render during fetch.
GPU + Worker
WebGL/Three.js (R3F) instanced rendering for nodes. Force-directed layout runs in a Web Worker off the main thread; positions streamed back per frame.

Focus ring is 2px #4c6ee6, always visible. Reduced-motion disables physics, pulse, and particle flow — swapping to instant state changes and static edges.
09 — Animation Grammar
Motion That Means Something
Every animation communicates a state change in the bicameral relationship — never decoration.
Memory Formation
New node scales from 0 → 1 with a spring (.5,1.4,.5,1), glow blooms then settles. 400ms. Signals: knowledge captured.
Alignment
Bridge edge draws left→right; pink particles flow along it, frequency = alignment strength. Two nodes ease closer together. Signals: hemispheres agree.
Approval
Approved node ripples an emerald ring outward once, badge stamps in. Gate unlocks downstream nodes with a staggered fade-in. Signals: human confirmed.
Conflict
Conflicting edge pulses red, connected nodes jitter subtly, a warning badge appears. Persists until resolved. Signals: needs human resolution.
Execution
Ready nodes emit a traveling pulse along dependency paths in sequence, mirroring build order. Signals: implementation flowing.
Stale / Decay
Untouched nodes slowly dim opacity and desaturate glow over time. Signals: memory aging, may need refresh.
