Design System
& Token Architecture
A three-tier token model — Primitives → Semantic aliases → Component tokens — themable across Light, Dark, and High-Contrast. Every value maps to an export-ready Tailwind key and CSS custom property for zero-interpretation developer handoff.
Tier 1
Primitives
Raw, theme-agnostic values. --indigo-500, --space-4. Never referenced directly in components.
Tier 2
Semantic Aliases
Intent-based, theme-switchable. --color-accent, --surface-raised. The layer themes remap.
Tier 3
Component Tokens
Component-scoped. --button-bg, --card-radius. Consume Tier 2, never Tier 1.

07 — Export-Ready Naming
Tailwind / React / CSS Map
One canonical name resolves across CSS custom properties, Tailwind config, and TypeScript token exports — zero translation needed at handoff.
// tokens.ts — TypeScript export
export const tokens = {
color: { accent: 'var(--color-accent)', hemisphereLeft: 'var(--hemisphere-left)', bridge: 'var(--bridge-align)' },
radius: { card: '22px', pill: '9999px' },
space: { 4: '16px', 8: '32px' },
motion: { durBase: '240ms', easeStandard: 'cubic-bezier(.2,0,0,1)' },
};
// tailwind.config.js — extend
theme.extend = {
colors: { accent: 'var(--color-accent)', 'left': 'var(--hemisphere-left)', 'right': 'var(--hemisphere-right)' },
borderRadius: { card: '22px' },
transitionTimingFunction: { standard: 'cubic-bezier(.2,0,0,1)' },
};
// theme switch — single root class
<html class="theme-dark"> → remaps all Tier-2 aliases
All tokens WCAG AA verified · contrast-checked in every theme · reduced-motion fallbacks defined for all motion durations.
